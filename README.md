# 📊 Acerto Fácil | Simulador de Rescisão Trabalhista

Uma aplicação web desenvolvida para fornecer estimativas rápidas, precisas e intuitivas sobre cálculos de rescisão contratual no regime CLT. O projeto traduz regras complexas de contabilidade trabalhista em uma interface amigável e acessível para o usuário final.

## 🎯 O Desafio e a Solução
Cálculos de rescisão (envolvendo FGTS, multas, aviso prévio, férias proporcionais e deduções como IRRF e Vale Transporte) costumam gerar dúvidas e insegurança para o trabalhador comum. 

O **Acerto Fácil** foi construído para resolver essa dor. Focando na experiência do usuário (UX), a ferramenta coleta os dados essenciais da rotina do trabalhador e aplica toda a lógica de negócios em tempo real, entregando uma prévia financeira clara e sem termos técnicos excessivos.

## ✨ Funcionalidades Principais
*   **Cálculo Automatizado:** Processamento instantâneo de dados com base na data de admissão, demissão e motivo do afastamento.
*   **Gestão de Variáveis Complexas:** Inclusão de variáveis como insalubridade, médias de comissões/horas extras e número de dependentes.
*   **Estimativa de Descontos:** Cálculo dinâmico de retenções, como o teto de 6% do Vale Transporte e faixas de IRRF.
*   **Interface Limpa e Responsiva:** Design corporativo e minimalista, focado em clareza da informação para qualquer dispositivo.

## 💻 Tecnologias Utilizadas
Para garantir máxima performance e demonstrar forte domínio dos fundamentos, este projeto foi desenvolvido sem o uso de frameworks JavaScript pesados:
*   **HTML5:** Estrutura semântica e acessibilidade.
*   **CSS3 & Tailwind CSS (v4):** Estilização moderna e utilitária, configurado nativamente via CLI para otimização de pacote.
*   **JavaScript (Vanilla):** Responsável por processar toda a lógica matemática complexa e atualizar o DOM de forma fluida.
*   **Lucide Icons:** Iconografia leve e escalável.
